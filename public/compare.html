SANDBOX

低完整性写边界，比单纯路径检查更硬。

不建议移植

  • Electron IPC 服务注册表 co()——本产品是 HTTP 边界（web-console + agent-server Router）。
  • CLI 子进程 per-session——同进程 ConversationRuntime 已等价且更轻。
  • RTB 设备桥——与本仓 remote.rs UpstreamProxy 方向相反。
  • Hyper-V microVM——低完整性路线更贴 Windows 单机架构。

方法论

分析全程离线只读：复制安装产物 → 解包 app.asar → 静态分析（约 1,599 个 IPC 操作、54 个 contextBridge API、70 条 sender 校验、42 个内置工具定义、系统 prompt 装配与 12 项停因闭集）。遇加密 / 完整性校验 / 凭据边界即停止记录，不做绕过。原始报告与完整比对表在分析仓（非公开分发）。

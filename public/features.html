THE SEVEN LAYERS

每一层，都有独立的设计

从目标进入运行时，到工具真正落地，再到结果被验证，七层各司其职。首页为每一层准备了独立的动态图示，这里给出能力边界与关键机制。

01 · ORCHESTRATION

多 Agent 协同编排

不同角色共享同一套会话、工具与权限边界。指挥官拆目标，规划者排步骤，执行者动手，验证者把关；需要并行时，子代理接手独立任务。

  • 多聊天室 Agent 并存，权限按聊天室归属。
  • chat_handoff 连同上下文交接任务。
  • 子代理并行处理独立子任务。
02 · COMPUTER USE

看得懂桌面，也点得准按钮

UIA 元素树与视觉模型双通道定位，把屏幕上的一个按钮变成可验证的坐标与动作。鼠标、键盘、拖拽、组合键都走安全点击路径。

  • UIA + 视觉坐标解析，多分辨率下仍能对准。
  • 安全点击、回收站删除、默认工程保护。
  • 外部目录写入逐次审批，完全访问重启失效。
03 · BROWSER USE

把浏览器变成 Agent 的另一双手

浏览器桥接让 Agent 操作真实网页，而不是只抓一段 HTML：语义定位元素、输入、点击、滑块、拖拽、组合键，按标签页租约隔离任务。

  • DOM 语义定位优先，视觉兜底。
  • 标签页租约避免任务互相抢页面。
  • 受限内部页与扩展页不直接操作。
04 · PLUGIN TOOLS

工具不是写死的，能力可以长出来

插件用 manifest 声明元数据、权限与工具清单，安装走原子事务：来源校验、兼容检查、失败回滚。9 个官方插件开箱即用，也可以封装团队工作流。

  • TDD、Git、评审、编排、文档、数据库、诊断、监控、市场。
  • 技能支持创建、安装、按会话启用。
  • 安装失败自动回滚，不留半装状态。
05 · PERMISSION & AUDIT

每一次放行，都留下证据

权限不是一句「允许访问」，而是一条可审计的链路：请求进入闸门，按聊天室与路径策略评估，高危动作等待人工批准，执行结果写回审计字段。

  • 未知权限元数据 fail-closed，不默放。
  • 审批可携带 updatedInput / updatedPermissions。
  • 可选 Windows 低完整性沙箱。
06 · GOAL PIPELINE

把长任务拆成可验收的四个阶段

commander → planner → implementer → verifier 的确定性流水线：验证门不过就带着原因回退重改，重试有上限，预算不被重置。

  • 验证门支持 FilesExist / Command。
  • implementer 受阻回 planner 重规划。
  • 阶段状态落 SQLite，可暂停、恢复、人工验收。
07 · PROVIDER ACCESS

一个总线，接住所有模态

文本、视觉、生图、生视频、本地模型走同一个 llm-adapter：OpenAI 兼容接口、订阅、OpenRouter、Ollama / 自定义端点，按模型类型独立配置。

  • 多模态与文本：Agnes 3.0 Flash、OpenAI 兼容、Devin、ChatGPT 订阅。
  • 生图 / 生视频：Agnes Image / Video、OpenRouter。
  • 本地：Ollama 或任意 OpenAI 兼容端点。

RUNTIME FOUNDATION

七层之下，是一台完整的本地运行时

能力层不是演示文稿里的方块。它们共享同一个会话循环、工具注册表、权限系统与持久化层。

TOOLS

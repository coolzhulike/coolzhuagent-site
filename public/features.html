FEATURES

特性总览

按运行时 → 工具 → 编排 → 交互 → 安全五层展开。每一项均对应仓库中的真实模块。

core-runtime

会话运行时

ConversationRuntime 驱动「模型回合 → 工具调用 → 结果回注」循环；流式输出、token 统计 （首 token 时间、缓存去重、解码速率如实展示）、上下文压缩。

tool-registry

内置工具

bash、powershell、read/write/edit、glob、grep、web fetch/search、todo、skill、repl、 结构化输出、子代理等 19+ 工具；统一权限裁决与执行协议。

plugin-system

插件系统

manifest 声明元数据/权限/工具清单；安装走原子事务并做来源与兼容校验；内置 TDD、 Git 工作流、代码评审、编排器、文档生成、数据库、诊断、监控、市场 9 个插件。

Goal

多阶段任务

commander / planner / implementer / verifier 流水线；确定性验证门（FilesExist/Command） 不过自动回退；重试带上限，预算不被重置。

computer-use

桌面操控

鼠标键盘、安全点击、分辨率映射、UIA 元素定位、视觉模型坐标解析、截图； 定时/后台/轨迹任务集中在任务页统一管理。

web-console

主控制台

九大主窗口：聊天室、任务、文件、终端、媒体、模型、设置等；单文件前端 内联进 Rust 服务，默认 http://127.0.0.1:8765/。

gui-desktop

桌面壳与桌宠

Tauri shell、桌宠、启动器；Q 版头像库（DeepSeek 鲸鱼娘系列）+ 自定义上传； 多开同端口实例经身份验证后平滑切换。

voice & media

语音与媒体

实时语音会话（STT ↔ 模型 ↔ TTS 闭环）；Agnes Image / Video、OpenRouter 渠道， 媒体用量与对话 token 分开统计。

bridge

桥接能力

浏览器桥接与微信私聊连接；聊天室可以驱动跨进程 Agent 对端（chat_handoff）。

workspace

工程与保护

多工程工作区；默认工程受保护（禁止移除/删除/重命名）；回收站删除； 路径显示去 \\?\ 前缀但保留原始路径做权限判断。

diagnostics

诊断与回归

发布前跑全量分组回归（0.2.142 记录：后端 1,539 项、前端 50 项、启动器 79 项）； 候选制品做隐私扫描与二进制哈希核对。

security

权限与隐私

权限按聊天室归属；外部目录逐次审批、完全访问二次确认且重启失效； 可选 Windows 低完整性沙箱；12 小时窗口自动清理运行记录。

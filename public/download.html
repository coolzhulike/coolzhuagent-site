校验下载完整性

安装包可能经镜像分发，务必核对哈希。PowerShell / CMD 均可用：

certutil -hashfile coolzhuagent-setup-x.y.z.msi SHA256

输出与本页 SHA-256 行完全一致（忽略大小写与空格）即为正品。不一致请更换渠道重新下载。

从源码构建

环境：Windows、Rust stable、PowerShell 5.1+。依赖已缓存时可离线构建：

cargo build -p coolzhu-web-console --offline
cargo run -p coolzhu-web-console -- --open

主控制台默认监听 http://127.0.0.1:8765/。MSI 打包见 scripts/build-msi.ps1。

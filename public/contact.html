BEFORE YOU WRITE

让反馈更快被处理

  • 附上版本号（下载页或应用「关于」可查）与 Windows 版本。
  • 描述最小复现步骤：做了什么、期望什么、实际发生了什么。
  • 涉及模型时说明 Provider 与模型 ID，但不要粘贴 API Key。
  • 涉及 Computer Use / Browser Use 时说明是否经过审批、是否可复现。

隐私说明

本页说明 coolzhuagent 官网与桌面应用的数据边界。原则很简单：站点不收集个人信息，应用本地优先，Agent 对话的 API Key 只留在服务端环境变量里。

本站

  • 不收集个人信息：无注册、无登录、无跟踪脚本、无第三方分析。
  • Agent 对话：你在首页中央 Agent 窗口输入的问题会发送到本站边缘函数 /api/chat，用于 FAQ 检索与回答；站点默认不持久化问题原文。
  • 模型调用：当站点内置的 Agnes Key 可用时，问题与检索到的 FAQ 上下文会发送给 Agnes（agnes-3.0-flash）生成回答。若模型不可用，则回退到 FAQ 检索或拒答。
  • 服务端 Key：Agnes API Key 仅配置在 EdgeOne 边缘函数环境变量中，不下发浏览器、不写入日志、不回显；模型请求由服务端发起，浏览器只发送问题文本。
  • 限流：为防止滥用与转售，同 IP 每日 5 次、全站每日 500 次，按 UTC+8 重置。IP 以加盐 SHA-256 哈希计数，不存原始 IP；限流存储不可用时拒绝请求（fail closed）。
  • AI 内容标识：Agent 回答由「FAQ 检索 + AI 辅助」生成，仅供参考，不构成价格、时效或功能承诺。
  • 日志：边缘函数仅记录请求量、命中来源、引擎、耗时等运行指标，不含问题原文、原始 IP 或 API Key。

coolzhuagent 应用

  • 本地优先：会话、聊天室、工程数据保存在你本机的工程目录（.coolzhu/）。
  • 出网边界：只有你主动发起的模型 API / 订阅调用会出网；本地工具与文件操作离线可用。
  • 凭据：模型密钥、登录凭据、会话数据库不进源码仓库、不上传本站。
  • 运行记录：按约 12 小时窗口自动清理，保护活动任务与聊天引用。
  • 权限：外部目录写入逐次审批；完全访问需二次确认且重启失效；可选 Windows 低完整性沙箱。

你的选择

  • 不使用 Agent 对话：首页其余内容不受影响。
  • 不要在对话中输入密码、API Key、身份证号等敏感信息。
  • 删除本地数据：卸载应用并删除工程目录即完成。
  • 疑问或删除请求：见联系页。
NOTE

关于第三方模型服务

当你使用站点内置额度调用 Agnes 时，问题内容会离开本站并受 Agnes 服务条款与隐私政策约束。请不要在对话中输入密码、密钥、身份证号等敏感信息。

# 常见问题

完整交互式问答请用右下角 FAQ 客服；此处是高频问题速查。

## 最新版本是多少？

0.2.142（2026-09）。更新摘要在[更新记录](/changelog.html)，完整验收记录在仓库 `docs/releases/`。

## 有没有便携版？

公开发布渠道筹备中；源码构建见[快速开始](/docs/quickstart.html)。

## 模型 Key 放哪里？

应用内「模型」设置分 API 与订阅两栏，Key 仅存本机，不进源码仓库、不上传本站。

## 删除文件会丢数据吗？

应用内删除走回收站；默认工程受保护不可删除。运行记录约 12 小时窗口自动清理。

## 怎么让 Agent 只做只读操作？

权限模式选 `ReadOnly`；外部目录写入永远逐次审批。详见[安全模型](/docs/security-model.html)。

## 客服回答可靠吗？

客服是「FAQ 检索 + AI 辅助」：命中知识库直接引用原文；拿不准会拒答并指到文档。
涉及版本号、下载地址的问题一律以下载页为准。
